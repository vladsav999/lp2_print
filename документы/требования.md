# Требования (вариант 31 «Сервис заказа печати»)

## Функциональные требования

| Код | Требование | Проверка |
|---|---|---|
| ФТ-01 | Форма загрузки файла с локального диска. | Выбрать файл, увидеть его имя. |
| ФТ-02 | Принимаются PDF, DOCX, JPG, PNG. | Иные файлы отклоняются с сообщением. |
| ФТ-03 | Проверяются обязательные поля: файл, копии, тип печати. | Все поля проверяются на заполненность. Количество копий нельзя выставить меньше 1. |
| ФТ-04 | Для PDF/DOCX определяется число страниц; изображение = 1 страница. | PDF на 5 стр. - «5». |
| ФТ-05 | Стоимость = страницы × копии × цена: ч/б -5 руб., цвет -12 руб. | Сверить с ручным расчётом. |
| ФТ-06 | Перед подтверждением выводится расчёт: страницы, копии, стоимость. | После запроса расчёта видны значения. |
| ФТ-07 | После подтверждения заказ сохраняется с уникальным номером. | Заказ появляется в очереди. |
| ФТ-08 | Заказ не создаётся при файле > 20 МБ или копиях = 0. | Появляется ошибка, записи нет. |

## Нефункциональные требования

| Код | Требование | Проверка |
|---|---|---|
| НФТ-01 | Расчёт до 100 страниц -не более 2 с. | Замерить 10 запросов. |
| НФТ-02 | Корректное отображение в Chrome и Opera. | Открыть в двух браузерах. |
| НФТ-03 | Ошибки на русском с указанием проблемного поля. | Проверить 3 ошибочных ввода. |
| НФТ-04 | Файлы не сохраняются после завершения сессии. | После перезапуска файлы исчезнут. |
