# Пользовательские сценарии

## UC-01 «Отправка задания на печать» (ключевой)
- Роль: клиент.
- Предусловие: открыт главный экран.
- Основной путь: выбрать файл - указать копии - выбрать тип печати - «Рассчитать» - получить стоимость - «Подтвердить» - получить номер.
- Альтернативы:
  - A1: нет копий - сообщение и возврат к вводу.
  - A2: файл > 20 МБ - отказ.
  - A3: недопустимый формат - отказ.
- Результат: заказ в очереди.

## UC-02 «Просмотр очереди»
- Роль: оператор.
- Поток: оператор открывает список заказов: номер, файл, страницы, статус.
- Результат: оператор видит заказы для выдачи.

## UC-03 «Отмена заказа»
- Роль: клиент.
- Предусловие: заказ в статусе «Ожидает».
- Поток: клиент отменяет заказ.
- Альтернатива: статус «В работе» - отказ.
- Результат: статус «Отменён».

## UC-04 «Повторный заказ»
- Роль: клиент.
- Предусловие: есть завершённый заказ.
- Поток: клиент повторяет завершённый заказ с теми же параметрами.
- Результат: создан новый заказ с новым номером.

## Критерии приёмки UC-01
1. При корректных данных стоимость = страницы * копии * цена.
2. При пустых копиях заказ не создаётся, выводится ошибка.
3. При файле > 20 МБ заказ не создаётся.
4. После подтверждения в очереди есть запись с уникальным номером.
