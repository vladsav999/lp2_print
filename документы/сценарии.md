# Пользовательские сценарии

## UC-01 «Отправка задания на печать» (ключевой)
- Роль: клиент.
- Предусловие: открыт главный экран.
- Основной поток:
  1. Клиент выбирает файл.
  2. Система показывает имя файла и число страниц.
  3. Клиент указывает копии.
  4. Клиент выбирает тип печати (ч/б или цветная).
  5. Клиент нажимает «Рассчитать».
  6. Система проверяет данные.
  7. Система показывает стоимость.
  8. Клиент нажимает «Подтвердить заказ».
  9. Система выдаёт номер.
- Альтернативы:
  - A1: копии = 0 → сообщение «Укажите количество копий», возврат к шагу 3.
  - A2: файл > 20 МБ → «Файл больше 20 МБ», возврат к шагу 1.
  - A3: недопустимый формат → «Недопустимый формат», возврат к шагу 1.
- Результат: заказ в очереди со статусом «Ожидает».

## UC-02 «Просмотр очереди»
- Роль: оператор.
- Предусловие: есть хотя бы один подтверждённый заказ.
- Поток: оператор открывает «Очередь», видит номер, имя файла, страницы, статус.
- Результат: оператор видит заказы для выдачи.

## UC-03 «Отмена заказа»
- Роль: клиент.
- Предусловие: заказ в статусе «Ожидает».
- Поток: клиент выбирает заказ, нажимает «Отменить».
- Альтернатива: статус «В работе» → отмена запрещена.
- Результат: статус «Отменён».

## UC-04 «Повторный заказ»
- Роль: клиент.
- Предусловие: есть завершённый заказ.
- Поток: клиент выбирает заказ, нажимает «Повторить», параметры подставляются.
- Результат: создан новый заказ с новым номером.

## Критерии приёмки UC-01
1. При корректных данных стоимость = страницы × копии × цена.
2. При копиях = 0 заказ не создаётся, выводится ошибка.
3. При файле > 20 МБ заказ не создаётся.
4. После подтверждения в очереди есть запись с уникальным номером.
